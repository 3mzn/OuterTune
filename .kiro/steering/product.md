# Product Overview

OuterTune is a Material 3 YouTube Music client and local music player for Android. It's a fork of InnerTune with enhanced features.

## Core Functionality

- YouTube Music streaming (no ads, background playback, offline downloads)
- Local audio file playback (MP3, OGG, FLAC, etc.)
- Hybrid playback: mix YouTube Music and local files in the same queue
- Account synchronization with YouTube Music
- Synchronized lyrics with word-by-word/karaoke support (LRC, TTML)
- Android Auto support

## Key Features

- Material 3 design language
- Multiple queue management
- Audio normalization, tempo/pitch adjustment, audio effects
- Custom tag extractor (fixes MediaStore metadata issues)
- Download manager for offline playback
- Lyrics from multiple providers (YouTube, LrcLib, KuGou, local files)

## Target Platform

- Android 8 (Oreo, API 24) and higher
- Primary support: Android 8+
- Unofficial support: Android 7.x (Nougat)

## Distribution

- GitHub Releases
- F-Droid
- IzzyOnDroid
- NOT on Google Play Store
